# Portfólio Pessoal — Wender Santos

## Sobre o projeto

Portfólio pessoal desenvolvido para a disciplina de Interface Homem-Máquina do curso de Análise e Desenvolvimento de Sistemas do IF Baiano — Campus Guanambi.

O site tem como objetivo apresentar minha formação, minhas habilidades e os projetos que desenvolvo durante meus estudos. O projeto está em desenvolvimento, com foco em uma interface organizada, acessível e adaptada para diferentes tamanhos de tela.

## Seções do site

- Início: apresentação pessoal e acesso às principais seções.
- Sobre mim: informações sobre minha trajetória e formação acadêmica.
- Projetos: apresentação dos trabalhos desenvolvidos, com imagens, descrições e links.
- Habilidades: conhecimentos e tecnologias que estou aprendendo.
- Contato: formulário e links para minhas redes.

## Tecnologias

O site será desenvolvido com:

- HTML5 para a estrutura e a organização semântica do conteúdo.
- CSS3 para a aparência, a responsividade e as animações.
- Flexbox e Grid para a organização dos elementos.
- Variáveis CSS para padronizar cores e outros estilos.

O formulário utilizará validação nativa do HTML, sem necessidade de JavaScript.

## Como visualizar

Baixe ou clone este repositório e abra o arquivo `index.html` no navegador.
